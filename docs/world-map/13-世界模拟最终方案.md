## 一、决策汇总（你的回答，逐条落定）

### 入口与首屏
| 议题 | 结论 |

| 入口 | 「世界」**改名「世界模拟」**，位置：主菜单 →「开始游戏」→ 第四个选项 |
| 与对话的关系 | **绑定当前对话存档**（世界跟着对话走） |

| 定位 | **申请 GPS 权限**；被拒 → 手动选城市 + 「用 IP 估测」两条都给 |
| 首屏全国地图 | **只画省级轮廓（31 个）** |
| 定位命中省 | **只高亮，等用户点「进入」**（不自动钻） |

### 存档地图
| 议题 | 结论 |
|---|---|
| 流程 | 选**对话存档** → 选**地图存档**；若该对话没地图但已聊很多轮 → **询问「是否根据全部上下文生成地图」** |
| 生成范围 | 对话里明确提到的地点 + 日程里出现过的地点 + 当前定位小区；**由「上帝 agent」总结必要地点，交给绘制 AI** |

### 头像 / 立绘 / 面板
| 议题 | 结论 |

### AI 移动
| 议题 | 结论 |
|---|---|
| 触发 | **每轮对话后**（AI 在回复**末尾**输出位置指令，**给用户看的文字里没有它**） |
| 速度 | **按现实速率**；长途用对应交通工具；**用户可选「现实时间」或「100× 加速」**（各交通工具速度不同） |

| 玩家干预 | 对话 + 地图拖拽**都支持**，但**在设置里可开关** |

### 事件系统

### UI / 性能 / 交付
| 议题 | 结论 |

## 二、架构（含新增的「上帝 agent」）

```
┌──────────────────── 对话（LingChat 原有） ────────────────────┐
│  用户 ↔ 角色（LLM 正常回复）                                    │
│      └─ 末尾附 ⟦wm:...⟧ 位置/动作指令                          │
│         ↓ processor.rs 解析（复用现有 【标签】管线）             │
│         ├─ following_text → 展示文字（已剥掉指令）✅ 用户看不到    │
│         └─ map_directive → 世界模拟                             │
└───────────────────────────────────────────────────────────────┘
                              ↓
┌──────────────────── 世界模拟（新增） ──────────────────────────┐
│ ① 场景管理器：当前 国/省/市/区县/小区 + 面包屑                     │
│ ② 角色驻留：日程→设施映射（已有） + AI 指令覆盖 + 移动动画          │
│ ③ 事件引擎：随机权重触发 10 类事件 → 通知（弹窗/气泡/角色说出）      │
│ ④ 上下文注入：变化时更新的固定段落 → 系统提示                      │
│ ⑤ 上帝 Agent（**已有**）：加一个工具，让它顺手汇报"必要地点"        │
│ ⑥ 存档桥：对话存档 ↔ 地图存档（含独立地图库）                      │
└───────────────────────────────────────────────────────────────┘
                              ↓
┌──────────────────── 地图（已有，Rust） ────────────────────────┐
│ 14 个模块 / 12+ 命令：coord geo render render_geo stats         │
│ sketch facilities transport schedule maplib osm stream ...     │
└───────────────────────────────────────────────────────────────┘
```

**「上帝 Agent」是已有的，不要新建**（这一条我之前设计错了，机主纠正）：

`src-tauri/src/ai_service/god_agent/` 本来就有 —— 它是**多人自由对话的 AI 导演**：
在自由对话且在场角色 > 1 时决定下一个发言者、限制 NPC 连轴转，
并且**自带可扩展的 function calling 工具注册**（现在只有一个 `select_next_speaker`）。
它已经挂在 `AppState`（`god_agent: Option<Arc<GodAgentCore>>`）并在回复管线（`message_system/generator.rs`）里被调用。

所以世界模拟要做的只是**给它加一个工具**，例如：

```rust
// god_agent/tools.rs 里照 select_next_speaker_tool() 的格式加
plan_map_locations_tool()      // 参数：locations: [{level, name, adcode?, reason}]
parse_map_locations(tool_call) // 容错解析（复用现成的 parse_tool_args）
```

**两个移动/编排机制各司其职**（不重复）：
| 机制 | 用在哪 | 成本 |
|---|---|---|
| 角色 LLM 末尾 `⟦wm:...⟧` | **角色自己的移动**（用户已定：免去判断、正文里看不到） | 几乎为零（只多几个 token） |
| 上帝 Agent 的工具调用 | **导演级决策**：谁发言、这场对话需要哪些地图 | 已有调用，加一个工具不增加往返 |

## 三、五个阶段（P1 → P5）

### P1 · 入口与首屏主线
- 「世界」改名「世界模拟」，进「开始游戏」子菜单第四个
- 首次引导：加载动画 → 全国省级轮廓 → 申请 GPS → 定位 → 高亮省 →（点进入）→ 市 → 弹确认 → 区县 → 小区
- 无权限/拒绝：手动选城市（三级联动+搜索）+ IP 估测
- 草图先出 + AI 绘制可视化叠加（复用 DistrictLive）
- 面包屑回退；加载动画（初始化/定位/地图加载/切换）
- **出口**：能一路走到小区地图并回退

### P2 · 人物在地图上
- 角色头像（随情绪）+ 玩家头像（可上传）落在地图
- 点击 → 侧边栏（桌面右侧滑出／手机全屏遮罩）+ 立绘（复用 `GameRoleAvatar`）
- 面板：7 项（角色）／5 项（自己）
- **出口**：点谁看谁，信息齐全

### P3 · 存档与注入
- 地图存档：选对话存档 → 选/建地图存档；无地图时询问是否按上下文生成
- 上帝 agent 总结地点 → 批量生成；每存档独立地图库
- 上下文注入（固定段落 + 变化时更新）
- **出口**：地图与存档、对话三方打通

### P4 · 会走动的世界
- `⟦wm:...⟧` 指令：prompt 说明 + 解析 + 剥离 + 前端应用
- 移动：现实速率 / 可选 100× 加速；短途走、长途乘车（含交通立绘）
- 玩家干预（对话 + 拖拽，设置可开关）
- 小地图
- **出口**：角色自己会动，且用户看得懂

### P5 · 事件与打磨
- 事件引擎：10 类 + 随机权重 + 三种通知（可选用哪些）
- 事件进记忆（按对话记忆的方式）
- 小清新皮肤定稿（先出 3 套预览给你选）+ 深色适配 + 手机等比缩放
- 性能档位适配、离线可看、内存小字显示
- **出口**：世界"活"起来且好看

## 四、关键技术点（已确认可行）

| 点 | 方案 | 依据 |
|---|---|---|
| 位置指令不露给用户 | 复用 `processor.rs` 的 `【标签】` 分段管线，`⟦⟧` 标记不进 `following_text` | 已有机制，实测可扩展 |
| 立绘 | 直接用素材里的 `正常.webp` 等（3511×5242）；**同时只显示一张**（≈73MB 内存，与聊天里现状持平） | 素材已存在 |
| 地图图片进 APK | `mapSvgUrl()` → `invoke('world_map_geo_svg')` → data URL；容器尺寸跟 `ResizeObserver` 走（画布与显示 1:1，手机字号实际放大 ≈2.7 倍） | 已实现并推送 |
| 定位 | 手动 → IP 兜底；GPS 需加插件+权限（P1 内做） | 已有 IP 实测 |
| 存档独立地图库 | `<data_dir>/world_map/saves/<存档id>/maplib` | maplib 已支持自定义根目录 |
| 上帝 agent | 一次结构化编排调用（不是常驻服务） | 新增 |
| 交通素材 | CC0 优先（[Kenney](https://kenney.nl/assets/pixel-vehicle-pack)、[SVG Silh](https://svgsilh.com/zh/ff0404/tag/%e8%bf%90%e8%be%93-15.html) 等）；风格统一由我重绘为扁平 SVG | 已检索 |
