# 20 · 老线（worldmap 原型）→ 新线（worldsim）移植方案

> 机主 2026-09-12 拍板：**老线那批能力全部移植到新线 `worldsim/`**，移植完老线即可删除。
> 本文是移植的施工图：每块能力从哪来、到哪去、依赖什么、怎么验。

---

## 一、为什么要移植（不是"为了好看"）

| 维度 | 老线 `worldmap/` + `public/world_map/*.js` | 新线 `worldsim/` |
|---|---|---|
| 前端形态 | 6 `.vue` + 1 `.ts` + **5 个裸 JS（5,668 行）塞在 `public/`** | 15 `.vue` + 18 `.ts`（`<script setup lang="ts">`） |
| 逻辑位置 | 业务逻辑写在静态目录的裸 JS 里 | `src/composables/useWorld*.ts` / `useWs*.ts` |
| 与官方一致性 | ❌ 官方仓库没有"把业务逻辑放 public 的裸 JS"这种做法 | ✅ 与官方同款（Vue3 + TS + Rust） |
| 提交 PR 时 | 5,668 行裸 JS 会是明显的非官方写法 | 干净 |

**结论：移植是让这套东西将来能作为 PR 提给上游的前提条件**，不只是审美问题。

> ⚠️ **T6-2 有机主追加需求（2026-09-12 卡片评论，移植时必须照做）**：
> > 「半透明指**小窗**在正常对话界面半透明**随着对话地点触发后才生效**，**小窗太小了**」
>
> 拆成三条硬要求：
> 1. **"半透明"说的是小窗，不是背景层** —— 主形态是**对话界面上的半透明小窗**
> 2. **要「随对话地点触发后才生效」** —— 不是常驻显示；当前对话的场景/位置命中地图时它才出现
>    （数据源现成：`wsRuntimePush.ts` 推的 `scene.area` / `actors[role].facility` 就是对话地点）
> 3. **小窗要大** —— 老线那个太小，移植时按新的尺寸重做（手机上要能看清地图内容，
>    参考 `worldmap.css` 里 `--ws-fs` 的缩放口径，别再用固定 px）
>
> 老线实现的问题：`WorldMapLayer.vue` 是**常驻挂载**（`App.vue:21` `v-if="isMainWindow"`），
> 没有"随对话地点触发"这一层，且尺寸偏小 —— 所以**不是照搬，是按上面三条重做**。

## 三、移植去向（新线目标文件）

| 能力 | 目标 | 做法要点 |
|---|---|---|
| 时间系统 | `src/composables/useWorldTime.ts` + `worldsim.css` 的 `.ws-tod-*` | 纯函数层（时段计算/色调映射）单独放 `wsTime.ts` 以便 node 自检；**色调只用 CSS 变量覆盖，不重画地图** |
| 天气视觉 | `src/composables/useWorldWeather.ts` + `WsWeatherLayer.vue` | 粒子用 `transform/opacity`（GPU 合成）；**低端机整层不挂载**（P5-5 的降级项） |
| NPC | `src/components/views/worldsim/WsNpcLayer.vue` + `wsNpc.ts` | 路人点继续用 canvas 批量绘制 + 视口裁剪（几千个点不能变几千个 DOM）；重大事件聚焦用现有 `WsEventBubble` 的定位逻辑 |
| 角色互动 | 并入 `WsCharPanel.vue` 的「关系」板块 | 现在那一栏是**启发式推断**（面板上已标注"仅供参考"）；移植后改为 `npc.js` 的真实关系落盘 |
| 交通工具绘线 | 扩 `wsVehicles.ts` + 新增 `WsTripPath.vue` | `drawTrip`/`drawRoute` 是 canvas 画法，新线是 SVG → 转成 `<path>` + `stroke-dasharray` 动画 |
| 悬浮手机 | `src/components/views/worldsim/WsPhone.vue` + `wsPhone/*.vue`（八项各一个小面板） | 外壳复用 `wsPanel.ts` 的模块级单例；八项分别接新线已有能力（见下表） |
| 地图库页面 | `src/components/views/worldsim/WsLibrary.vue` | 走已有的 `world_map_maplib_*` 命令；**清理必须 dry_run 默认** |
| 半透明叠加 | `WorldSim.vue` 增加 `overlay` 模式 + 挂到 `App.vue` | 官方 z-index 现实：背景 `-2` → 立绘 `1` → 地图层 `1`（同值后插入者在上面）→ 菜单 `1000`。要当**背景层**必须 z-index < 1 |

## 四、施工顺序（每波一个可独立验收的切片）
