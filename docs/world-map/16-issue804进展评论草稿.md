## 关于你说的「真实地理下钻有点逆天」

这句我们认真想过了喵，补几个数据给你判断：

- 首屏**只画省级轮廓（34 个）**，不画全国几千个区划 → 打开就是秒开喵
- 行政区划走**本地缓存**，只有没去过的省市才联网喵
- 区划图做了像素级简化，一张大概 100KB 喵
- 手机上的字号问题用「画布尺寸跟着屏幕走」解决掉了（以前是一张 1000px 的图缩到 400px 看喵）

所以**"真实地理"这块其实不贵喵**；真正花时间的是"世界模拟"那层玩法（事件 / 移动 / 立绘喵），
而那层可以单独开关，不影响基础地图喵～
